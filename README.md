# Moinuddin Chisty Shaik — Portfolio

A responsive React + Vite portfolio built from the supplied professional brief.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Before deployment

The supplied brief did not include a direct email address or resume PDF. Add them in `src/data.js` and `public/` respectively, then add the appropriate links in `src/App.jsx`.

All portfolio content is intentionally centralized in `src/data.js` to make routine updates quick.
